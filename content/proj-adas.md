## ③ 车载主动安全系统（联咏 NT98323）

> 复习指引：讲"从零搭框架 + 报警链路"两条线，突出框架搭建能力和平台通信经验，7x24 稳定性单独准备。
> 重要度：★★★★
> 复习重点：SPI/UART 外设对接、多线程与 IPC 选型、报警上传链路（YUV→算法→CURL/HTTP）、SQLite 掉电不丢、崩溃恢复（Zlog/信号）。

### 项目一句话

公交/商用车主动安全系统，实现 DMS 驾驶员监测 + ADAS 预警，报警上传平台。

### 项目 STAR

**背景**：公交/商用车有主动安全需求：DMS 驾驶员监测 + ADAS 预警，报警要上传平台。

**我的职责**：搭建软件框架并实现报警链路。

- 框架搭建：Zlog 日志、IPC、平台通信链路、协议处理
- 对接盲区/倒车雷达外设，数据采集与接口开发
- 报警生成：从视频监控取 YUV 灌入虹软/魔视算法，生成 DMS/ADAS 报警，CURL 上传报警视频/图像
- SQLite 持久化设备/报警/算法参数；开发与 Android APP 的接口，支持远程配置

**技术亮点**：

- 从零搭建软件框架（日志/IPC/通信/协议），支撑整个产品
- YUV 灌入算法驱动报警生成 + CURL 上传报警视频/图像
- SQLite 掉电不丢 + APP 远程配置闭环

**结果**：按项目交付，宁波公交等批量部署

### 必考知识点（点击直达对应页面）

- [55. SPI 详解与四种模式](#/12-embedded?goto=55. SPI 详解与四种模式)——SPI 四线 MOSI/MISO/SCLK/CS，单主多从靠 CS 选从机，全双工高速，四种模式 = CPOL × CPHA，收发双方必须一致；`面试怎么挂钩`：对接盲区/倒车雷达外设的 SPI 通信，模式匹配是联调第一步。
- [52. UART 详解与 USART 区别](#/12-embedded?goto=52. UART 详解与 USART 区别)——UART 帧格式为起始位 + 数据位（LSB 先发）+ 校验位 + 停止位，9600bps 每 bit ≈ 104.2µs，接线交叉共地；`面试怎么挂钩`：雷达等外设的串口数据采集与调试口输出都走 UART。
- [同步互斥全家桶对比（互斥锁/信号量/条件变量/自旋锁/读写锁）](#/03-os?goto=同步互斥全家桶对比（互斥锁/信号量/条件变量/自旋锁/读写锁）)——互斥锁独占、信号量计数、条件变量等条件、自旋锁忙等不睡眠、读写锁读多写少提升并发；`面试怎么挂钩`：多路传感器线程并发读、决策线程偶尔写，用读写锁降低读侧互斥开销。
- [IPC 对比（管道/消息队列/共享内存/信号量/socket）](#/03-os?goto=IPC 对比（管道/消息队列/共享内存/信号量/socket）)——共享内存吞吐量最大但要自己加锁同步、信号量用于同步/互斥、socket 最通用可跨主机，选型口诀"大数据共享内存+信号量，命令/事件用消息队列或 socket"；`面试怎么挂钩`：系统进程与 Android APP 通信（socket/共享内存）实现远程配置，IPC 选型能讲出理由。
- [信号处理（SIGSEGV/SIGPIPE/SIGCHLD，关联崩溃恢复）](#/03-os?goto=信号处理（SIGSEGV/SIGPIPE/SIGCHLD，关联崩溃恢复）)——SIGSEGV 等默认终止并可产生 core，SIGPIPE 默认终止写端工程上常忽略，handler 里只能调 async-signal-safe 函数；`面试怎么挂钩`：Zlog 日志 + 崩溃恢复，报警上传对端关闭时忽略 SIGPIPE 避免进程莫名退出。
- [HTTP/HTTPS 与 TLS 握手简述](#/04-net?goto=HTTP/HTTPS 与 TLS 握手简述)——HTTP 是无状态的明文请求/响应协议，状态码分 1xx~5xx；HTTPS 加 TLS 加密层，握手协商套件、校验证书后转入对称加密；`面试怎么挂钩`：报警视频/图像用 CURL 上传平台，上传失败要能看状态码和 TLS 证书定位。
- [内存泄漏常见场景与避免](#/13-memory?goto=内存泄漏常见场景与避免)——泄漏 = 申请的堆内存失去引用且未释放：提前 return 漏释放、fd 未关闭、基类析构非 virtual 等，valgrind 的 definitely lost 就是泄漏；`面试怎么挂钩`：设备 7x24 运行，YUV 缓冲/上传队列必须"谁申请谁释放"，定期用 valgrind 扫描。
- [56. GPIO 与外部中断触发模式](#/12-embedded?goto=56. GPIO 与外部中断触发模式)——GPIO 输入/输出/复用/模拟四种模式，外部中断有上升沿、下降沿、双边沿、电平触发，按键需消抖；`面试怎么挂钩`：雷达脉冲/唤醒信号检测，边沿触发 + 消抖是嵌入式标配。
- [环形缓冲区（加锁版与无锁版思路）](#/02-c?goto=环形缓冲区（加锁版与无锁版思路）)——环形缓冲区用 head/tail 指针 + 模运算实现 FIFO，留一格区分空/满，SPSC 可无锁；`面试怎么挂钩`：CAN/外设报文接收队列就是环形缓冲，与 YUV 灌入算法的内存映射减少拷贝呼应。

### 面试追问 Q&A

- **Q：** YUV 数据多大？怎么保证灌入算法的实时性？
- **A：** 【待补充：分辨率/帧率，如 1080p@25fps 约 4MB/帧】；通过内存映射或环形缓冲减少拷贝，独立线程灌入，保证算法帧率。
- **Q：** 报警上传失败怎么办？
- **A：** 队列缓存 + 重试机制，网络恢复后补传，避免报警丢失。
- **Q：** 系统进程和 Android APP 怎么通信？
- **A：** 按实际（socket/共享内存）；我开发了跨平台接口，支持 APP 远程配置系统和算法参数。
- **Q：** DMS/ADAS 报警怎么生成的？
- **A：** 从视频监控取指定通道 YUV 灌入虹软/魔视算法，算法输出事件后转成统一报警结构，附视频/图像经 CURL 上传平台。
- **Q：** 为什么用 SQLite 存数据？
- **A：** 单文件轻量、掉电不丢，适合存设备信息、报警记录、算法参数，也方便 APP 远程配置读写。
- **Q：** 报警量大时会不会丢报警？
- **A：** 本地队列 + SQLite 落盘 + 断网重传三保险；队列水位超限时优先保留高危报警【按实际补充容量】。
- **Q：** Zlog 日志框架怎么搭的？
- **A：** 分级日志（DEBUG/INFO/WARN/ERROR）+ 滚动落盘 + 崩溃时打印调用栈，支撑现场问题回溯。
