### 必考知识点（点击直达对应页面）

- [9. 串口通信](#/12-embedded?goto=9. 串口通信)——UART 是异步串行通信，收发双方必须约定相同波特率；TTL 板内短距离、RS-232 抗干扰点对点、RS-485 差分多点半双工；`面试怎么挂钩`：GPS 模块通过串口输出 NMEA 报文（$GPRMC 等），实时解析经纬度/速度/航向。
- [socket 编程：TCP/UDP 客户端与服务器骨架](#/04-net?goto=socket 编程：TCP/UDP 客户端与服务器骨架)——TCP 服务端 socket→bind→listen→accept→recv/send，客户端 socket→connect→send/recv，每个调用都要检查返回值并处理 EINTR/EAGAIN；`面试怎么挂钩`：一体机作为 TCP 客户端与后台平台稳定通信，支持后台调度指令。
- [字符串函数 strlen/strcpy/memcpy/memmove 与安全版本](#/02-c?goto=字符串函数 strlen/strcpy/memcpy/memmove 与安全版本)——strlen 不含结束符，strcpy 不检查目标空间不安全，strncpy 可能不补 '\0'，memcpy 不处理内存重叠、memmove 处理，生产代码用安全版本；`面试怎么挂钩`：NMEA 是逗号分隔的文本帧，GPS 解析就是字符串拆字段，必须用安全函数防越界。
- [10. 定时器](#/12-embedded?goto=10. 定时器)——定时器 = 计数器 + 时钟源，计数到 0 触发中断，用于定时调度、超时检测、看门狗、心跳上报；`面试怎么挂钩`：自动报站的站点轮询匹配、心跳上报与看门狗保活都依赖定时器。
- [1. 面向对象三大特性：封装 / 继承 / 多态](#/11-cpp?goto=1. 面向对象三大特性：封装 / 继承 / 多态)——封装隐藏内部实现、继承实现代码复用、多态让"同一接口、不同实现"，多态需虚函数 + 派生类重写 + 基类指针/引用调用；`面试怎么挂钩`：Qt UI 与业务逻辑都用 C++ 面向对象设计，界面控件继承 QWidget、信号槽跨线程解耦。
- [长连接 vs 短连接](#/04-net?goto=长连接 vs 短连接)——长连接一次建立多次传输、省去频繁握手开销，适合高频率小数据量通信；短连接每次新建用完即关、握手开销大；`面试怎么挂钩`：一体机与后台是长连接 + 心跳保活，断线自动重连并补传数据。
- [IPC 对比（管道/消息队列/共享内存/信号量/socket）](#/03-os?goto=IPC 对比（管道/消息队列/共享内存/信号量/socket）)——共享内存吞吐量最大但要自己加锁同步，信号量用于同步/互斥而非传数据，socket 最通用可跨主机；`面试怎么挂钩`：车辆数据采集进程与上报进程用共享内存 + 信号量做零拷贝交换。
- [死锁四条件与预防](#/03-os?goto=死锁四条件与预防)——死锁四条件：互斥、持有并等待、不可剥夺、循环等待，破坏任意一个即可预防，工程上用全局统一加锁顺序 + 超时加锁；`面试怎么挂钩`：多模块共享总线与日志锁，制定统一加锁顺序规范，避免偶发卡死。

### 面试追问 Q&A

- **Q：** 自动报站怎么判断到站？
- **A：** 经纬度匹配站点库为主，航向和速度辅助判断，加偏差修正，避免误报/漏报。
- **Q：** 区域限速怎么实现？
- **A：** 电子围栏 + 限速阈值下发，车辆进入围栏后按阈值执行限速策略。
- **Q：** TCP 与后台通信断线怎么办？
- **A：** 断线重连 + 数据本地缓存，恢复后补传，保证指令和报站数据不丢【具体策略按实际补充】。
- **Q：** 3000 台现场支持遇到过什么难题？
- **A：** 疑难问题解决率 95% 以上。按"现象 → 复现 → 抓日志 → 定位 → 解决"挑一个实际案例讲【按实际准备】。
- **Q：** GPS 信号丢失时自动报站怎么处理？
- **A：** 依赖站点轮询缓存 + 速度/航向推算兜底，超时未恢复则提示"定位异常"避免误报【按实际补充策略】。
- **Q：** Qt 界面与业务线程怎么解耦？
- **A：** 界面线程只管 UI，业务逻辑放工作线程，用 Qt 信号槽/队列连接跨线程通信，避免界面卡死。
